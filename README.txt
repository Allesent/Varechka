МИР ВАРИ — персональный сайт-портрет

Сайт посвящён Варе. В нём собраны её портрет личности, черты характера,
привычки, любимые вещи, интересы, маленькие радости, необычные факты,
мечты, любимая музыка, кино, фотографии и видео.

Структура:
- index.html — сайт
- style.css — оформление и адаптация
- script.js — интерактивность и музыкальный плеер
- assets/ — фотографии и обложки видео
- videos/ — пять видео Вари
- audio/amy.mp3 — Amy — Kai Angel

Публикация:
Загрузите всё содержимое папки проекта в корень GitHub-репозитория
и включите GitHub Pages (Settings → Pages → Deploy from a branch → main → /(root)).

Примечание:
Портрет личности оформлен на основе ответов Вари. Сайт содержит личные сведения,
поэтому перед публикацией по открытой ссылке стоит убедиться, что Варя согласна
размещать эти детали публично.
